# 🍽️ MealMate – AI-Powered Food Ordering & Recipe Recommendation Platform

> An intelligent Full Stack Food Ordering Platform that combines AI-powered recipe recommendations, restaurant discovery, secure authentication, online ordering, and responsive user experience to simplify everyday meal planning.

🌐 **Live Demo:** https://mealmate-6.onrender.com

---

# 📖 Overview

MealMate is a modern AI-powered Full Stack web application designed to provide users with a seamless food ordering and meal discovery experience. The platform integrates intelligent recipe recommendations, restaurant exploration, secure user authentication, responsive UI, and online food ordering into a single scalable application.

The project demonstrates modern software engineering principles including responsive frontend development, backend integration, authentication, REST API implementation, scalable architecture, cloud deployment, and user-centric application design.

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/Shivanand6/mealmate_6.git
```

Navigate to the project directory

```bash
cd mealmate_6
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the development server

```bash
python manage.py runserver
```
